# Security

Champollion checks local files. It does not upload texts, call translation models,
or execute instructions embedded in a work or profile. Source acquisition is a
separate operation. Protect private texts and any evidence you choose to publish.

Use a tagged release and verify its archive against the release's SHA256SUMS.
A vendor manifest detects accidental changes; it is not a signature or proof that
an untrusted source is safe. Review an upstream update before accepting its hashes.

Report a reproducible security problem through [Mouseia's contact page](https://mouseia.org/contact).
Include the affected version and a minimal synthetic reproduction, not credentials
or private source texts. Avoid publishing exploit details before a fix is available.

Version 1.x receives fixes. No response-time or security-certification guarantee is offered.
